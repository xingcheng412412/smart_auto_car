# 手动启动 SocketCAN 脚本设计

## 目标

提供一个可手动执行的脚本，让用户输入 sudo 密码后，将指定 CAN 接口配置为指定波特率并启动。默认接口为 `can0`，默认波特率为 `500000` bit/s。

## 使用接口

默认运行：

```bash
./script/start_can.sh
```

指定接口和波特率：

```bash
./script/start_can.sh can1 500000
```

第一个位置参数是接口名，第二个位置参数是十进制波特率。

## 行为

脚本使用 Bash 严格模式，并依次执行：

1. 检查 `ip` 命令是否存在。
2. 验证接口名仅含字母、数字、下划线、句点和连字符。
3. 验证波特率是正整数。
4. 检查目标网络接口是否存在。
5. 通过 `sudo` 获取权限。
6. 将接口置为 down。
7. 设置 CAN 波特率。
8. 将接口置为 up。
9. 使用 `ip -details link show` 验证接口为 UP、CAN 状态不是 STOPPED，并显示最终配置。

任何步骤失败时，脚本输出明确错误并返回非零退出码。重复运行脚本应得到相同的有效配置。

## 范围

- 创建 `script/start_can.sh` 并赋予可执行权限。
- 在 README 的 SocketCAN 配置章节中增加脚本用法。
- 不配置开机自启。
- 不自动启动 ROS2 节点。
- 不修改远程工控机文件；脚本由用户自行复制或同步后运行。

## 验证

- 使用 `bash -n script/start_can.sh` 检查语法。
- 使用不合法接口名和波特率验证参数检查在调用 sudo 前失败。
- 使用不存在的接口验证错误信息和非零退出码。
- 在有 CAN 硬件的工控机上运行后，通过 `ip -details -statistics link show can0` 确认 `UP`、`ERROR-ACTIVE` 和 `bitrate 500000`。
